# Phase 01: Molecular Foundations

## Scientific question

How does a DNA sequence determine a protein's chemistry, and how does that chemistry govern which
molecules it interacts with? Two systems are used to answer it:

- **Sugarcane:** how the drought-response receptor ScPYL61 senses the plant hormone abscisic acid (ABA).
- **Sickle cell:** how one nucleotide change in HBB makes deoxygenated hemoglobin molecules stick together.
