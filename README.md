# Computational Biochemistry Lab

A GitHub-first lab record for learning computational biochemistry and molecular dynamics,
following the Atu Labs curriculum. Every phase runs two tracks side by side:

- **Sugarcane:** drought response through ABA signalling (ScPYL61 and partners).
- **Sickle cell disease:** the HBB Glu→Val mutation and how sickle hemoglobin (HbS) aggregates.

Each module ends with a comparison: what carried over between the two systems, and what was
specific to one biology.

## Layout

```
src/cb/        reusable, domain-independent Python package (tested)
tests/         tests for src/cb, mirroring its layout
phases/NN-*/   one folder per phase
  <track>/data/raw/       downloaded inputs, never edited; listed in data/SOURCES.md
  <track>/notebooks/      numbered to match the modules: 01_, 02_, 03_
  <track>/results/        figures and tables generated by notebooks only
  <track>/notes/          research notes
  comparisons/            paired sugarcane × sickle-cell reflections
  references/             bibliography
```

**Rule of thumb:** if code works the same for any organism (parsing FASTA, translating codons,
computing ΔG), it goes in `src/cb/` with tests. Facts about a specific biology (which codon is
mutated, which residues bind ABA) stay in that track's notebooks and notes.

## Setup

Requires [uv](https://docs.astral.sh/uv/).

```bash
uv sync                  # create .venv from uv.lock
uv run pytest            # run tests
uv run jupyter lab       # open notebooks
```
